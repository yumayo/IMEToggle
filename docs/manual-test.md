# Windowsでの手動確認

日本語のMicrosoft IMEを選択し、英語配列キーボードからF13・F14が送信される状態で確認します。

1. `docker compose exec -T dev sh /usr/local/bin/imetoggle-build` を実行し、9件のテスト・Windows向けビルド・DLL依存の検査が成功すること。
2. `out\docker\IMEToggle.exe` をWindowsの任意のフォルダーにコピーして起動する。exe単体で起動し、トレイに緑色の「あ」が表示され、コンソールやメインウィンドウが開かないこと。
3. メモ帳の入力欄でF13を押して `abc` と打ち、英数になること。F13をもう一度押しても英数のままであること。
4. F14を押して `aiueo` と打ち、日本語になること。入力を確定してからF14をもう一度押しても日本語のままであること。
5. F13・F14を交互に押し、明示した状態になること。長押しでON/OFFが反転しないこと。
6. 変換中の未確定文字列がある状態でF13を押し、確定・次の入力が通常のMicrosoft IMEのOFF操作と同じように動くこと。
7. ブラウザーの検索欄と普段使うエディターでも手順3〜6を確認する。アプリを切り替えた直後でもF13・F14が動くこと。
8. Ctrl・Shift・Alt・WinとF13/F14の組み合わせが、入力先アプリの元のショートカットとして処理されること。修飾キーを先に離しても、その押下中にIME操作へ変わらないこと。
9. トレイメニューの「一時停止」で灰色になり、F13・F14が元のキーとして入力先へ渡ること。再開するとIME操作に戻ること。
10. 二重に起動すると案内が表示され、二重にフックされないこと。もう一方のアプリは動作を続けること。
11. 「ログイン時に起動」を有効にして、Windowsへ再ログインすると起動すること。無効にして再ログインすると起動しないこと。実行ファイルのパスに空白がある場所でも確認すること。
12. 終了後にトレイアイコンが消え、F13・F14が元のキーに戻ること。
13. 起動中にExplorerを再起動し、トレイアイコンが再表示されてキー操作を続けられること。
14. Windowsの拡大率を100%・150%・200%・300%に設定し、トレイアイコンと「使い方」ダイアログ、右クリックメニューが読みやすいサイズで表示されること。アイコンがぼやけたり、文字が切れたりしないこと。一時停止中の灰色アイコンも確認すること。
15. 起動したまま拡大率を変更し、再起動せずに表示が更新されること。異なる拡大率のモニター間でメインディスプレイやタスクバーの表示先を切り替え、トレイアイコン・メニュー・ダイアログが表示先の拡大率に追従すること。
16. 高DPI環境でExplorerを再起動した場合と、モニターを接続・切断した場合も、表示とF13・F14の動作が正常であること。

必要に応じて、管理者権限の入力先や使用中のキーボード割り当てツールとの併用も確認してください。Windowsのバージョン、IME設定、アプリ名と結果を記録すると、互換性の問題を切り分けやすくなります。
